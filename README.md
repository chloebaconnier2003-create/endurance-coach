# Endurance Coach V2

Application web responsive de coaching multisport adaptatif pour une préparation vers le LéMan Full Distance 2027.

## Fonctionnalités actuelles

- check-in quotidien récupération/douleur ;
- Decision Engine adaptatif ;
- planning automatique court ;
- gardes 24 h / 12 h ;
- rugby, danse, renforcement et triathlon ;
- objectifs et missions personnelles ;
- charge sRPE et historique ;
- Athlete Model V1.

## Lancement local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Déploiement

Le point d'entrée Streamlit est `app.py`.

> Outil de planification sportive. Ne remplace pas un avis médical.
